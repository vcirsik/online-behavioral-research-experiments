# Behavioral Research Experiments

A collection of browser-based experiments developed using JavaScript and HTML to support behavioral and experimental research.
These projects demonstrate the technical implementation of experimental research designs, including interactive tasks, controlled stimulus presentation, participant response collection, and behavioral measurement.

Areas of Focus:
- Experimental design and implementation
- Interactive behavioral research tasks
- JavaScript and HTML programming
- Participant response collection and behavioral measurement
- Custom research tools and data collection workflows

About This Repository
These projects represent earlier work in auditory cogntive neuroscience research . They demonstrate my experience translating research methodologies into functional, browser-based experiments.
My more recent professional work focuses on quantitative and mixed-methods UX research, customer behavior analysis, and advanced SQL-based analytics.
